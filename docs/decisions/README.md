# Decision Records

This directory contains all the Architecture Decision Records (ADRs) created during the development of **Swiss Data Intelligence**.

The purpose of these documents is to record significant technical and product decisions made throughout the project.

Each ADR captures:

- the problem or context
- the available alternatives
- the selected solution
- the rationale behind the decision
- its consequences
- potential future revisions

These documents serve three purposes:

1. Document the evolution of the project.
2. Support the technical report of the CAS.
3. Explain the reasoning behind architectural and engineering decisions.

Only significant decisions are documented.

Implementation details and minor coding choices are intentionally excluded.

> **Note**
>
> ADRs are numbered sequentially in the order the decisions were made, not in the order they were implemented.

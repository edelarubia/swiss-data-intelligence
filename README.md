# Swiss Data Intelligence

> **An AI-powered platform for exploring Swiss public datasets through natural language, analytics, machine learning and visualization.**

---

## Overview

Swiss Data Intelligence is the final project developed as part of the **CAS in Machine Learning** at the **Lucerne University of Applied Sciences and Arts (HSLU)**.

The project aims to build a modular AI platform that transforms publicly available Swiss datasets into meaningful insights through data analytics, machine learning and natural language interaction.

Rather than being a single-purpose application, the platform is designed as a foundation that can evolve into multiple intelligence modules built on a shared architecture.

---

## Project Objectives

The project has four main objectives:

- Develop a technically robust and academically defensible CAS project.
- Build a real AI product rather than a standalone notebook or proof of concept.
- Create a professional GitHub portfolio demonstrating software engineering and applied AI skills.
- Strengthen professional positioning for Data Scientist, Machine Learning Engineer and AI Engineer roles in Switzerland.

---

## Initial MVP

The first version focuses on publicly available Swiss datasets related to:

- Housing
- Demographics

The MVP will demonstrate an end-to-end workflow including:

- Data ingestion
- Data preparation
- Exploratory data analysis
- Interactive visualizations
- Machine learning
- Natural language exploration

Future versions may expand into additional domains such as labour market, health insurance and cost of living intelligence.

The platform is primarily built using publicly available Swiss datasets, including:

- Federal Office of Public Health (FOPH/BAG)
- Other official Swiss public data providers
